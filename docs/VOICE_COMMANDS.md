# Saathi voice commands

Tap **Speak** (big yellow button at the bottom), wait for the beep, then say a command.
Hindi and Punjabi words work too. The words can be anywhere in your sentence.

| Say | Hindi / Punjabi | Does |
|---|---|---|
| navigate / read mode | नेविगेट / ਨੈਵੀਗੇਟ, रीड मोड | Open a mode |
| home, go back | वापस, होम / ਵਾਪਸ | Home screen |
| repeat | दोबारा / ਦੁਬਾਰਾ | Say the last answer again |
| stop, quiet | रुको, चुप / ਰੁਕੋ | Stop talking, scanning, directions |
| what's ahead, describe, look | सामने क्या है / ਸਾਹਮਣੇ ਕੀ ਹੈ | Describe the path ahead |
| read the sign | साइन पढ़ो / ਸਾਈਨ ਪੜ੍ਹੋ | Read a sign |
| which bin | कौन सा डिब्बा / ਕਿਹੜਾ ਡੱਬਾ | Which bin for this item |
| find the bin | डिब्बा ढूँढो / ਡੱਬਾ ਲੱਭੋ | Bin finder |
| take me to the bus stand | बस स्टैंड ले चलो / ਬੱਸ ਅੱਡੇ ਲੈ ਚੱਲੋ | Walking directions |
| where is the nearest pharmacy | | Walking directions |
| where am I | मैं कहाँ हूँ / ਮੈਂ ਕਿੱਥੇ ਹਾਂ | Current street and place |
| directions | रास्ता / ਰਸਤਾ | While walking: repeat the next turn |
| stop directions | रास्ता बंद / ਰਸਤਾ ਬੰਦ | End directions |
| obstacles on / off | रुकावट चालू / बंद | Obstacle alerts |
| read this, scan | पढ़ो / ਪੜ੍ਹੋ | Guided document scan |
| more, read all | और बताओ / ਹੋਰ ਦੱਸੋ | Full text or bill items |
| count money | पैसे गिनो / ਪੈਸੇ ਗਿਣੋ | Count notes and coins |
| I paid 500 | 500 दिए / 500 ਦਿੱਤੇ | Tell it what you paid |
| check my change | छुट्टा जाँचो / ਭਾਨ ਜਾਂਚੋ | Check the change |
| is this note fake | नकली है क्या / ਨਕਲੀ | Fake-note check |
| any other question (Read mode) | | Asked about the last document |

How it stays accurate: the phone gives up to 5 guesses of what you said and Saathi takes the first one that is a real
command; English words must match whole words; a long question in Read mode ("can I change the date?") is treated as a
question, not as a command.
